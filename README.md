# 📌 Research Status

Welcome to the research repository for **SD-Learner (Single Domain Learner)**.


This repository presents the architecture, methodology, and summarized experimental results of SD-Learner, a hybrid Graph Neural Network integrated with Meta Learning designed for few shot graph classification in biomedical graphs.

> **Publication Notice**
>
> The accompanying manuscript has not yet been formally published. Therefore, the complete implementation, trained models, and manuscript are intentionally withheld until completion of the publication process.



---

# 📖 Overview

**SD-Learner (Single Domain Learner)** is an original research project that explores graph representation learning for biomedical graph classification under limited-data learning environments.

The project investigates modern Artificial Intelligence techniques for improving graph learning performance where only a small number of labeled training examples are available.

This repository has been designed as a research showcase rather than an implementation repository. Its purpose is to provide an organized presentation of the research progress while respecting the ongoing peer-review process.

Visitors can explore selected research assets including methodology illustrations, conceptual framework diagrams, experimental visualizations, and repository updates without exposing unpublished technical contributions.

---

# 🎯 Research Motivation

Graph-structured data plays a fundamental role in numerous biomedical applications, including molecular analysis, drug discovery, protein interaction studies, and biological network modeling.

Although Graph Neural Networks have demonstrated remarkable success across these domains, learning robust representations from limited labeled data remains a significant research challenge.

This project investigates approaches that improve learning capability under few-shot settings while maintaining strong graph representation quality and classification performance.

The work contributes to ongoing research efforts in Machine Learning and Biomedical Artificial Intelligence by exploring techniques designed for graph-based learning problems where data availability is limited.
